द्विघात समीकरण (Quadratic Equations)

जिस समीकरण में चर की उच्चतम घात 2 हो, उसे द्विघात समीकरण कहते हैं। इसका मानक रूप ax² + bx + c = 0 है, जहाँ a ≠ 0 और a, b, c वास्तविक संख्याएँ हैं।

1. गुणनखंड विधि

समीकरण को ऐसे दो गुणनखंडों के गुणनफल में लिखते हैं जिनका गुणनफल शून्य हो। शून्य गुणनफल नियम के अनुसार कम-से-कम एक गुणनखंड शून्य होगा।

उदाहरण: x² − 5x + 6 = 0 को (x − 2)(x − 3) = 0 लिख सकते हैं। इसलिए x = 2 या x = 3।

2. द्विघात सूत्र

जब गुणनखंड आसानी से न बनें, तब मूल निकालने के लिए सूत्र का उपयोग कर सकते हैं:

x = (−b ± √(b² − 4ac)) / 2a

3. विविक्तकर और मूलों की प्रकृति

D = b² − 4ac को विविक्तकर कहते हैं। यदि D > 0 तो दो अलग-अलग वास्तविक मूल, D = 0 तो दो समान वास्तविक मूल, और D < 0 तो कोई वास्तविक मूल नहीं होता।

उदाहरण: x² − 4x + 4 = 0 में a = 1, b = −4, c = 4। D = 16 − 16 = 0, इसलिए दोनों मूल समान हैं। समीकरण (x − 2)² = 0 है और मूल 2 है।

अभ्यास

  1. x² − 7x + 10 = 0 को गुणनखंड से हल करें।
  2. x² + 2x + 1 = 0 का विविक्तकर निकालें।
  3. 3x² − 2x + 5 = 0 में D का चिह्न क्या होगा?
उत्तर देखें
  1. (x − 5)(x − 2) = 0, मूल 5 और 2।
  2. D = 4 − 4 = 0।
  3. D = 4 − 60 = −56, इसलिए कोई वास्तविक मूल नहीं।
याद रखें: सूत्र लगाने से पहले a, b और c के चिह्न सही पहचानें।
